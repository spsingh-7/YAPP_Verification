# YAPP_Verification
UVM Verification Environment for YAPP Router


In this project an End-to-End UVM-based verification environment has been developed to verify a YAPP Router.

The DUT is a packet router that accepts YAPP-formatted data packets on a single input data port and routes them to one of three output channels based on header address fields. Includes internal registers, error detection via parity checks, and control/configuration interfaces (such as an HBUS interface).
